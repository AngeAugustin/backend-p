# AI Accounting Balance Management — LuxAIIT

Web app for accounting balance analysis with automatic generation, dashboards, and LLM-powered explanations.

## Case study

Development of a web application for managing and analyzing accounting balances with artificial intelligence.

From an annual accounting balance, the solution automatically builds master sheets and yearly results. It also provides interactive dashboards and detailed explanations to support analysis.

Built with React JS, Django, and PostgreSQL, it integrates an LLM-based AI layer. The project was fully deployed on Contabo.
