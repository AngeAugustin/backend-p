# AML Suspicious Transaction Detection — Govern Group

Machine Learning AML engine to detect suspicious patterns in Core Banking transaction flows.

## Case study

Development of an Anti-Money Laundering (AML) system designed to analyze banking transaction flows from a Core Banking system.

It uses Machine Learning techniques to identify suspicious transaction patterns that may be linked to money laundering or terrorism financing.

Built with Python and exposed through a REST API for integration into the GRC SaaS, especially the AML/CFT/PF module.

## Tech stack

- Python
- Machine Learning
- API REST
