# Banking Management Web App — Freelance

Banking platform simulator with a structured frontend/backend architecture and UML modeling.

## Case study

Design and development of a banking management web application that simulates the main features of a banking platform.

The frontend was built with React JS while the backend relies on Nest JS and Node JS. Components communicate through a REST API, with data stored in MySQL.

The project also includes UML analysis and modeling, plus a structured frontend/backend architecture.

## Tech stack

- React JS
- Nest JS
- Node JS
- MySQL
- API REST
