# Pension Case Tracking — CNSS Benin

Web application for tracking pension cases at CNSS Benin, with a frontend/backend architecture and REST API.

## Case study

Development of a web application dedicated to tracking pension cases at CNSS Benin. The project covers UML analysis and modeling, frontend interface design with React JS, and backend development with PHP Symfony 6.

The application relies on a frontend/backend architecture connected via a REST API and integrates a MySQL database to manage and track pension case information.

## Tech stack

- React JS
- Symfony 6
- MySQL
- API REST
