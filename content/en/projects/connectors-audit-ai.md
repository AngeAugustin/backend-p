# Connectors & AI Audit Platform — LuxAIIT

Connector platform to audit databases, REST/SOAP APIs, email services, and servers, enriched with LLMs.

## Case study

Design and development of a web connector platform to interact with heterogeneous data sources and IT systems.

The framework connects to databases, REST and SOAP APIs, email services, and servers to retrieve specific information and perform technical and functional audits.

It analyzes connection history, privileges, structural changes, detected conflicts, and certain vulnerabilities. Built with React JS, Django, PostgreSQL, Redis, and a generative AI layer.

## Tech stack

- React JS
- Django
- PostgreSQL
- Redis
- IA/LLM
- API REST
- SOAP
