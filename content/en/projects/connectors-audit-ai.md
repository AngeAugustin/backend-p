# Connectors & AI Audit Platform — LuxAIIT

Connector platform to audit databases, REST/SOAP APIs, email services, and servers, enriched with LLMs.

## Case study

Design and development of a connector web platform to interact with different data sources and IT systems.

The framework connects to databases, REST and SOAP APIs, email services, and various servers to collect specific information and run technical and functional audits.

It analyzes connection history, privileges, structural changes, detected conflicts, and some vulnerabilities. Built with React JS, Django, PostgreSQL, Redis, and a generative AI layer.

## Tech stack

- React JS
- Django
- PostgreSQL
- Redis
- IA/LLM
- API REST
- SOAP
