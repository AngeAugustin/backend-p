# Packaging Sales CRM — Freelance Benin

Web CRM to centralize sales, appointments, deliveries, support, and commercial follow-up, also packaged as an Electron desktop app.

## Case study

Development of a web CRM dedicated to packaging sales management. The solution helps the company centralize sales, transaction history, client appointments, delivery scheduling, customer support, and commercial follow-up.

Built with React JS on the frontend and Symfony 6 on the backend, communicating via a REST API with a PostgreSQL database.

The project also includes packaging the web app as a desktop application with Electron JS, plus deployment on Vercel and a Hostinger VPS.

## Tech stack

- React JS
- Symfony 6
- PostgreSQL
- Electron JS
- API REST
