# Tutoring Management Platform — Freelance Benin

Web and mobile platform helping parents find and hire full-time or on-demand tutors for their children.

## Case study

Design and development of a web and mobile tutoring management platform that helps parents find and hire full-time or on-demand tutors for their children.

The project includes a React JS and React Native frontend, and a PHP Symfony 6 backend. Interfaces communicate through a REST API, with MySQL for data management.

A test version of the mobile app was deployed on the Play Store. The web frontend was deployed on Vercel and the backend on a Hostinger VPS.

## Tech stack

- React JS
- React Native
- Symfony 6
- MySQL
- API REST
