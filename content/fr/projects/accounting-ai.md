# Gestion de bilan comptable avec IA — LuxAIIT

Application web d’analyse de bilans comptables avec génération automatique, dashboards et explications LLM.

## Étude de cas

Développement d'une application web de gestion et d'analyse de bilans comptables intégrant l'intelligence artificielle.

La solution permet, à partir du bilan comptable annuel, d'établir automatiquement les feuilles maîtresses et le résultat de l'année. Elle propose également des tableaux de bord interactifs ainsi que des explications détaillées pour faciliter l'analyse des résultats.

Développée avec React JS, Django et PostgreSQL, elle intègre une couche IA basée sur les LLM. Le projet a été entièrement déployé sur Contabo.
