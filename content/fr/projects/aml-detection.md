# Système AML de détection des transactions suspectes — Govern Group

Moteur AML en Machine Learning pour détecter des schémas suspects dans les flux d’un Core Banking.

## Étude de cas

Développement d'un système AML (Anti-Money Laundering) de lutte contre le blanchiment d'argent, conçu pour analyser les flux de transactions bancaires provenant d'un Core Banking.

Le système utilise des techniques de Machine Learning afin d'identifier des schémas de transactions suspectes pouvant être associés au blanchiment d'argent ou au financement du terrorisme.

Solution développée en Python et exposée via une API REST pour intégration au SaaS GRC, notamment au module LCB-FT-FP.

## Stack technique

- Python
- Machine Learning
- API REST
