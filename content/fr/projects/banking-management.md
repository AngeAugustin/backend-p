# Application web de gestion bancaire — Freelance

Simulateur de plateforme bancaire avec architecture frontend/backend structurée et modélisation UML.

## Étude de cas

Conception et développement d'une application web de gestion bancaire destinée à simuler les principales fonctionnalités d'une plateforme bancaire.

Le frontend a été développé avec React JS tandis que le backend repose sur Nest JS et Node JS. Les composants communiquent via une API REST et les données sont stockées dans MySQL.

Le projet comprend également l'analyse et la modélisation UML ainsi que la mise en place d'une architecture frontend/backend structurée.

## Stack technique

- React JS
- Nest JS
- Node JS
- MySQL
- API REST
