# Suivi des dossiers de pension — CNSS Bénin

Application web de suivi des dossiers de pension à la CNSS Bénin, avec architecture frontend/backend et API REST.

## Étude de cas

Développement d'une application web dédiée au suivi des dossiers de pension à la CNSS Bénin. Le projet couvre l'analyse et la modélisation UML, la conception de l'interface frontend avec React JS ainsi que le développement du backend avec PHP Symfony 6.

L'application repose sur une architecture frontend/backend connectée via une API REST et intègre une base de données MySQL pour assurer la gestion et le suivi des informations relatives aux dossiers de pension.

## Stack technique

- React JS
- Symfony 6
- MySQL
- API REST
