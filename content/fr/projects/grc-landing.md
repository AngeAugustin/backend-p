# Landing Page SaaS GRC — Govern Group

Site vitrine du SaaS GRC présentant fonctionnalités, roadmap et assistance conversationnelle IA.

## Étude de cas

Conception et développement d'une landing page professionnelle pour un SaaS de Gouvernance, Risques et Conformité (GRC).

Le site web vitrine présente le SaaS, ses principales fonctionnalités ainsi que sa roadmap, avec pour objectif une présentation claire et structurée de la solution.

Interface développée avec Vite, TypeScript, Tailwind CSS et Shadcn UI, avec une assistance conversationnelle basée sur l'IA. Une version de test a été déployée sur Vercel.

## Stack technique

- Vite
- TypeScript
- Tailwind CSS
- Shadcn UI
- Intelligence Artificielle
