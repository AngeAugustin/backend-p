# CRM de gestion des ventes de packaging — Freelance Bénin

CRM web pour centraliser ventes, rendez-vous, livraisons, support client et suivi commercial, aussi packagé en desktop Electron.

## Étude de cas

Développement d'une application web CRM dédiée à la gestion des ventes de packaging. La solution permet à l'entreprise de centraliser la gestion de ses ventes, l'historique des transactions, les rendez-vous clients, la programmation des livraisons, le support client et le suivi commercial.

L'application a été développée avec React JS pour le frontend et Symfony 6 pour le backend, avec une communication via API REST et une base PostgreSQL.

Le projet comprend également le packaging de l'application web en application desktop avec Electron JS, ainsi que son déploiement sur Vercel et VPS Hostinger.

## Stack technique

- React JS
- Symfony 6
- PostgreSQL
- Electron JS
- API REST
