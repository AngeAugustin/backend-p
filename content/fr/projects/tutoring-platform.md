# Plateforme de gestion du tutorat — Freelance Bénin

Application web et mobile permettant aux parents de rechercher et d’engager des tuteurs pour leurs enfants.

## Étude de cas

Conception et développement d'une plateforme web et mobile de gestion du tutorat permettant aux parents de rechercher et d'engager des tuteurs à temps plein ou de manière ponctuelle pour leurs enfants.

Le projet comprend le développement du frontend avec React JS et React Native, ainsi que du backend avec PHP Symfony 6. Les interfaces communiquent via une API REST, avec MySQL pour la gestion des données.

Une version de test de l'application mobile a été déployée sur le Play Store. Le frontend web a été déployé sur Vercel et le backend sur un VPS Hostinger.

## Stack technique

- React JS
- React Native
- Symfony 6
- MySQL
- API REST
